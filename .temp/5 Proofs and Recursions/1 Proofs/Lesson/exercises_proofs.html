1Vocabulary recap easy

Match each term with the right definition: axiom, conjecture, lemma, theorem, corollary, proof.

Solution
  • Axiom — a self-evident proposition accepted without proof.
  • Conjecture — an unproven proposition consistent with current data.
  • Lemma — a short theorem used to prove a larger one.
  • Theorem — a proposition proven true by rigorous argument.
  • Corollary — a statement that follows immediately from a theorem.
  • Proof — a rigorous mathematical demonstration that a proposition is true.

2Direct: sum of two odd integers is even easy

Prove that if $a, b$ are odd, then $a + b$ is even. Then verify in Python on a range.

Solution

Write $a = 2k + 1$ and $b = 2m + 1$ with $k, m \in \mathbb{Z}$. Then $a + b = 2k + 2m + 2 = 2(k + m + 1)$, even. $\square$

Python — empirical check for a in range(-50, 51): for b in range(-50, 51): if a % 2 == 1 and b % 2 == 1: assert (a + b) % 2 == 0 print("Holds for all odd pairs in [-50, 50] ✓")

3Direct: product of two rationals is rational easy

Write the direct proof, then check three random pairs of rationals in Python with fractions.Fraction.

Solution

$x = \dfrac{a}{b},\; y = \dfrac{c}{d}$ with $b,d \neq 0$ gives $xy = \dfrac{ac}{bd}$ where $bd \neq 0$. $\square$

Python from fractions import Fraction import random for _ in range(3): x = Fraction(random.randint(-9, 9), random.randint(1, 9)) y = Fraction(random.randint(-9, 9), random.randint(1, 9)) p = x * y print(f"{x} * {y} = {p} (rational? {isinstance(p, Fraction)})")

4Contraposition: $n^2$ even $\Rightarrow n$ even medium

Prove by contraposition that for every $n \in \mathbb{Z}$, if $n^2$ is even then $n$ is even.

Solution

Contrapositive: if $n$ is odd, then $n^2$ is odd.

If $n = 2k + 1$ then $n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$, odd. $\square$

Python — empirical contrapositive for n in range(-200, 201): if n % 2 == 1: assert (n*n) % 2 == 1 print("Contrapositive holds in [-200, 200] ✓")

5Contraposition: $ab < 0 \Rightarrow a < 0 \vee b < 0$ medium

Prove by contraposition for $a, b \in \mathbb{R}$.

Solution

Contrapositive: $\neg(a<0 \vee b<0) \Rightarrow \neg(ab<0)$, i.e. $a \geq 0 \wedge b \geq 0 \Rightarrow ab \geq 0$.

The product of two non-negative numbers is non-negative — direct arithmetic. $\square$

Python — check the contrapositive import itertools for a, b in itertools.product(range(0, 10), repeat=2): assert a * b >= 0 print("Holds on all non-negative pairs ✓")

6Contradiction: $\sqrt{2}$ is irrational medium

Reproduce the classical proof in 4 steps. Verify the conclusion symbolically with SymPy.

Solution
  1. Suppose $\sqrt{2} = \dfrac{p}{q}$, $\gcd(p, q) = 1$.
  2. $2 q^2 = p^2 \Rightarrow p^2$ even $\Rightarrow p$ even, write $p = 2k$.
  3. $2 q^2 = 4k^2 \Rightarrow q^2 = 2k^2 \Rightarrow q$ even.
  4. $p$ and $q$ both even contradicts $\gcd(p, q) = 1$. $\square$
SymPy from sympy import sqrt print(sqrt(2).is_rational) # False print(sqrt(2).is_irrational) # True

7Contradiction: infinitely many primes (Euclid) hard

Reproduce Euclid's argument. Then write Python code that, for a list of "all" primes $L = [2, 3, 5, \dots, p_n]$, builds $q = 1 + \prod L$ and verifies that $q$ has a prime factor not in $L$ (for $n \leq 6$).

Solution
Python — illustrating Euclid's construction from math import prod from sympy import primerange, factorint for n in range(1, 7): L = list(primerange(2, [3, 5, 7, 11, 13, 17, 19][n])) q = 1 + prod(L) factors = factorint(q) print(f"L = {L}\n q = {q}, factors = {factors}\n")

Each $q$ either is itself a prime larger than any in $L$, or has a prime factor outside $L$. Either way, $L$ is not the complete list — contradiction. $\square$

8Cases: $n^2 - 1$ is divisible by 3 when $3 \nmid n$ medium

Prove by cases and verify on a range.

Solution

If $n$ is not divisible by 3, then $n = 3k + 1$ or $n = 3k + 2$.

  • $n = 3k + 1: n^2 - 1 = 9k^2 + 6k = 3(3k^2 + 2k)$.
  • $n = 3k + 2: n^2 - 1 = 9k^2 + 12k + 3 = 3(3k^2 + 4k + 1)$.

Both divisible by 3. $\square$

Python for n in range(-1000, 1001): if n % 3 != 0: assert (n*n - 1) % 3 == 0 print("OK on [-1000, 1000] ✓")

9Cases: $n^2 \bmod 4 \in \{0, 1\}$ medium

Prove that for every $n \in \mathbb{Z}$, $n^2 \equiv 0$ or $1 \pmod 4$.

Solution
  • $n = 2k$: $n^2 = 4k^2 \equiv 0 \pmod 4$.
  • $n = 2k + 1$: $n^2 = 4k^2 + 4k + 1 \equiv 1 \pmod 4$. $\square$
Python residues = {(n*n) % 4 for n in range(-500, 501)} print(residues) # {0, 1}

10Existence: find a SAT witness medium

Show that $(\neg x \vee y \vee z) \wedge (x \vee \neg y \vee z) \wedge (x \vee y \vee \neg z) \wedge (x \vee y \vee z)$ is satisfiable by exhibiting an assignment.

Solution
SymPy from sympy.abc import x, y, z from sympy import And, Or, Not from sympy.logic.inference import satisfiable f = And(Or(Not(x), y, z), Or(x, Not(y), z), Or(x, y, Not(z)), Or(x, y, z)) print(satisfiable(f)) # {x: True, y: True, z: True}

Any assignment where at least one of $x, y, z$ is True works, e.g. $(x, y, z) = (\text{T}, \text{T}, \text{T})$. $\square$

11Uniqueness: 2 is the only even prime medium

Show existence and uniqueness; back it up with a Python scan up to 10 000.

Solution

Existence: 2 is prime and even.
Uniqueness: if $p$ is even, $2 \mid p$. If $p$ is also prime, the only positive divisors of $p$ are 1 and $p$, so $2 \in \{1, p\}$, hence $p = 2$. $\square$

Python from sympy import isprime print([n for n in range(2, 10_001) if n % 2 == 0 and isprime(n)]) # [2]

12Disprove a conjecture by counterexample hard

Someone claims: "For every $n \in \mathbb{N}$, $n^2 + n + 41$ is prime." Use Python to either confirm it or find the smallest counterexample.

Solution

The claim is famous from Euler. It holds for $n = 0, 1, \dots, 39$ but fails at $n = 40$:

$40^2 + 40 + 41 = 1681 = 41 \cdot 41$, not prime. $\square$

Python — find the smallest counterexample from sympy import isprime for n in range(1000): val = n*n + n + 41 if not isprime(val): print(f"First counterexample: n={n}, val={val}") break
Output First counterexample: n=40, val=1681
