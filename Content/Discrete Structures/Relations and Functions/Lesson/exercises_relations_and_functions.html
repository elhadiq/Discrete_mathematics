1Relation as a set of tuples easy

Let $A = \{1, 2, 3\}$ and $B = \{a, b, c\}$. Define the relation $R = \{(1, a), (1, b), (2, c), (3, b)\}$.

  1. Verify that $R \subseteq A \times B$.
  2. List all elements in $A$ that have at least one image in $R$ (the domain of definition).
  3. List all elements in $B$ that appear as an image (the image set).
Solution
Python A = {1, 2, 3} B = {"a", "b", "c"} R = {(1,"a"), (1,"b"), (2,"c"), (3,"b")} print(R.issubset({(a,b) for a in A for b in B})) # True print({a for a, _ in R}) # {1, 2, 3} print({b for _, b in R}) # {'a', 'b', 'c'}

2Is this a function? easy

For each relation on $A = \{1, 2, 3, 4\}$, decide whether it is a function. Use Python.

  1. $R_1 = \{(1, 1), (2, 4), (3, 9), (4, 16)\}$
  2. $R_2 = \{(1, 1), (1, 2), (2, 4), (3, 9), (4, 16)\}$
  3. $R_3 = \{(1, 1), (2, 4), (3, 9)\}$ — domain still $A = \{1,2,3,4\}$
Solution
Python def is_function(R, A): counts = {a: 0 for a in A} for a, _ in R: counts[a] += 1 return all(c == 1 for c in counts.values()) A = {1, 2, 3, 4} print(is_function({(1,1),(2,4),(3,9),(4,16)}, A)) # True print(is_function({(1,1),(1,2),(2,4),(3,9),(4,16)},A)) # False (1 has 2 images) print(is_function({(1,1),(2,4),(3,9)}, A)) # False (4 has no image)

3Domain & range (finite) easy

Given the dictionary f = {1:'a', 2:'b', 3:'a', 4:'c', 5:'b'}, compute the domain, the image, and the preimage of 'a' and of 'b'.

Solution
Python f = {1:'a', 2:'b', 3:'a', 4:'c', 5:'b'} domain = set(f.keys()) image = set(f.values()) preimage_a = {k for k, v in f.items() if v == 'a'} preimage_b = {k for k, v in f.items() if v == 'b'} print(domain, image) # {1,2,3,4,5} {'a','b','c'} print(preimage_a, preimage_b) # {1,3} {2,5}

4Domain of $\dfrac{\sqrt{x-3}}{x-7}$ medium

Find the (real) domain of $f(x) = \dfrac{\sqrt{x-3}}{x-7}$, both by hand and with SymPy.

Solution

By hand: need $x - 3 \geq 0$ and $x - 7 \neq 0$, hence $x \in [3, 7) \cup (7, \infty)$.

SymPy from sympy import symbols, sqrt, S from sympy.calculus.util import continuous_domain x = symbols('x', real=True) f = sqrt(x - 3) / (x - 7) print(continuous_domain(f, x, S.Reals)) # Union(Interval.Ropen(3, 7), Interval.open(7, oo))

5Injectivity test medium

Decide whether each of these is injective on its domain:

  1. $f_1(x) = 3x - 4$ on $\mathbb{R}$
  2. $f_2(x) = x^2 - 4x + 7$ on $\mathbb{R}$
  3. $f_3(x) = x^2 - 4x + 7$ on $[2, \infty)$
  4. $f_4 = \{1\!\to\!a,\, 2\!\to\!b,\, 3\!\to\!a\}$
Solution
SymPy from sympy import symbols, solve, Eq x1, x2 = symbols('x1 x2', real=True) def injective(expr, var=x1): expr1 = expr expr2 = expr.subs(var, x2) sols = solve(Eq(expr1, expr2), x1) return sols == [x2] # only solution must be x1 = x2 print(injective(3*x1 - 4)) # True print(injective(x1**2 - 4*x1 + 7)) # False (parabola)

$f_3$: restricted to $x \geq 2$ the parabola is strictly increasing — injective.
$f_4$: not injective since $f(1) = f(3) = a$.

6Surjectivity test medium

Is the function $f : \mathbb{R} \to \mathbb{R},\; f(x) = e^x$ surjective? What about $f : \mathbb{R} \to (0, \infty),\; f(x) = e^x$?

Solution
SymPy from sympy import symbols, exp, S from sympy.calculus.util import function_range x = symbols('x', real=True) print(function_range(exp(x), x, S.Reals)) # Interval.open(0, oo)

The range is $(0, \infty)$. Therefore $f : \mathbb{R} \to \mathbb{R}$ is not surjective (negative reals and 0 are unreached), but $f : \mathbb{R} \to (0, \infty)$ is surjective (and in fact bijective).

7Inverse of a finite bijection medium

Let $f = \{1\!\to\!v,\, 2\!\to\!x,\, 3\!\to\!w,\, 4\!\to\!z\}$ from $\{1,2,3,4\}$ to $\{v,w,x,z\}$. Build $f^{-1}$ and verify $f^{-1}(f(k)) = k$ for every key.

Solution
Python f = {1:'v', 2:'x', 3:'w', 4:'z'} def invert(f_dict): if len(set(f_dict.values())) != len(f_dict): raise ValueError("not injective — no inverse") return {v: k for k, v in f_dict.items()} f_inv = invert(f) print(f_inv) # {'v':1, 'x':2, 'w':3, 'z':4} for k in f: assert f_inv[f[k]] == k print("Inverse correct ✓")

8Symbolic inverse medium

Find the inverse of $f(x) = 2x + 5$ and of $g(x) = \dfrac{x-1}{x+1}$. Verify with SymPy.

Solution
SymPy from sympy import symbols, solve, Eq, simplify x, y = symbols('x y', real=True) print(solve(Eq(y, 2*x + 5), x)) # [y/2 - 5/2] print(solve(Eq(y, (x-1)/(x+1)), x)) # [-(y+1)/(y-1)] # Check g(g_inv(y)) == y g = (x - 1) / (x + 1) g_inv = -(y + 1) / (y - 1) print(simplify(g.subs(x, g_inv) - y)) # 0

9Composition medium

Let $f(x) = x^2 + 1$ and $g(x) = 2x - 3$. Compute $f \circ g$ and $g \circ f$ symbolically with SymPy, then verify numerically that $f(g(2)) = 2$ and $g(f(2)) = 7$.

Solution
SymPy from sympy import symbols, Lambda, expand x = symbols('x') f = Lambda(x, x**2 + 1) g = Lambda(x, 2*x - 3) print(expand(f(g(x)))) # 4*x**2 - 12*x + 10 print(expand(g(f(x)))) # 2*x**2 - 1 print(f(g(2))) # f(1) = 2 print(g(f(2))) # g(5) = 7

10Pipe of $n$ functions hard

Write pipe(*fs) such that pipe(f1, f2, …, fn)(x) = fn(…f2(f1(x))) (left-to-right). Then write compose(*fs) for the mathematical right-to-left convention (f1(f2(…fn(x)))).

Solution
Python from functools import reduce def pipe(*fs): return lambda x: reduce(lambda v, f: f(v), fs, x) def compose(*fs): return pipe(*reversed(fs)) inc = lambda x: x + 1 twice = lambda x: x * 2 sq = lambda x: x * x print(pipe(inc, twice, sq)(3)) # ((3+1)*2)**2 = 64 print(compose(sq, twice, inc)(3)) # same result, mathematical order

11$x^2$ vs $x^3$ — invertibility hard

Decide whether each is invertible on its stated domain, and give the inverse when it exists.

  1. $f(x) = x^2$ on $\mathbb{R}$
  2. $f(x) = x^2$ on $[0, \infty)$
  3. $f(x) = x^3$ on $\mathbb{R}$
Solution

(1) Not invertible — fails the horizontal-line test.
(2) Invertible; $f^{-1}(y) = \sqrt{y}$ on $[0, \infty)$.
(3) Invertible; $f^{-1}(y) = y^{1/3}$ on $\mathbb{R}$.

SymPy from sympy import symbols, solve, Eq, Interval, S from sympy.calculus.util import function_range x, y = symbols('x y', real=True) print(solve(Eq(y, x**2), x)) # [-sqrt(y), sqrt(y)] → ambiguous print(function_range(x**2, x, Interval(0, S.Infinity))) # [0, oo) — bijection here print(solve(Eq(y, x**3), x)) # [y**(1/3)] (real branch)

12Sigmoid example hard

Let $f(x) = \dfrac{-x}{-1+x}$ and $g(x) = \log(x)$. Compute $h = f^{-1} \circ g^{-1}$, then find its domain and range with SymPy. Recognize the result.

Solution
SymPy from sympy import symbols, log, exp, solve, Eq, simplify, S from sympy.calculus.util import continuous_domain, function_range x, y = symbols('x y', real=True) f_inv = solve(Eq(y, -x/(-1+x)), x)[0] # y/(1+y) g_inv = solve(Eq(y, log(x)), x)[0] # exp(y) h = simplify(f_inv.subs(y, g_inv.subs(y, x))) print(h) # exp(x)/(1 + exp(x)) print(continuous_domain(h, x, S.Reals)) # (-oo, oo) print(function_range (h, x, S.Reals)) # (0, 1)

$h(x) = \dfrac{e^x}{1 + e^x}$ is the logistic / sigmoid function — domain $\mathbb{R}$, range $(0, 1)$.
