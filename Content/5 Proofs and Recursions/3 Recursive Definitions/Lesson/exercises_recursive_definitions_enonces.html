15Mandelbrot escape time hard

The recursion is $z_{n+1} = z_n^2 + c$, $z_0 = 0$. The point $c \in \mathbb{C}$ is in the Mandelbrot set iff this sequence remains bounded (in fact iff $|z_n| \leq 2$ forever).

  1. Implement mandelbrot(c, max_iter=80) that returns the first $n$ for which $|z_n| > 2$, or max_iter if no escape.
  2. Decide if $c = 0$, $c = -1$, $c = 1$, $c = 0.25 + 0.5 j$ are in the Mandelbrot set.
  3. (Optional) Render a small ASCII or matplotlib picture over $[-2, 1] \times [-1.2, 1.2]$.
