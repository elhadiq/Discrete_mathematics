Project — 3-SAT as a Graph-Coloring Problem

Open the attached file Project_3SAT_Coloring_student.html in your browser. It explains the problem from scratch (with drawings and worked examples) and contains the three tasks to complete: build_sat_graph, three_color, and decode.

What to submit

  • A single Jupyter notebook (.ipynb) with all cells executed so the outputs are visible.
  • The self-test cells should print Task 1 ✔, Task 2 ✔, Task 3 ✔, and the final Challenge ✔.
Rules
  • Work on your own. A notebook that still contains errors is accepted and graded fairly — partial or imperfect work is fine.
  • What is not accepted is work done with the help of AI tools (ChatGPT, Copilot, etc.). Submissions produced with AI assistance will not be graded.
  • Questions: please use the course discussion forum — not private messages — so everyone benefits from the answers.
