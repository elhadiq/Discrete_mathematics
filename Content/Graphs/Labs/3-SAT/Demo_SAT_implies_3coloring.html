Why a satisfying assignment gives a 3-coloring

3-SAT as Graph-Coloring — the direction $\varphi$ is satisfiable $\Rightarrow$ $G_\varphi$ is 3-colorable

Notes By Pr. El Hadiq Zouhair

↔ companion page: the other direction (3-colorable ⟹ satisfiable)

This page proves the second half of the reduction. The first page showed a coloring gives a solution; here we go the other way — we start from a satisfying assignment and build a proper 3-coloring of $G_\varphi$. Together the two halves give the full equivalence.

Suppose $\varphi$ is satisfiable, and fix any assignment that satisfies it. Then we can properly 3-color $G_\varphi$: color the base triangle, color each literal by its truth value, and complete each gadget. Hence $G_\varphi$ is 3-colorable.

Unlike the other direction, this is a construction: we are handed the truth values and must produce the colors. Three colors, named by the base triangle as before.

T color = True F color = False B color = Base

Step 1 — Color the base triangle

Give T, F, B three different colors and keep them fixed. From now on we color by these anchors: a vertex "gets the T-color," "gets the F-color," etc.

Step 2 — Color each literal by its truth value

For every variable x, use the assignment:

  • if x is True: color vertex x with the T-color and vertex ~x with the F-color;
  • if x is False: do the opposite (x → F-color, ~x → T-color).

This always colors the variable triangle x – ~x – B properly: x and ~x get different colors (T and F), and both differ from B's color.

A True variable: x takes the T-color, ~x the F-color (swap if False).

Step 3 — The OR gadget can always be completed

Given the colors of its inputs, an OR gadget can be properly colored so that the output takes the T-color whenever at least one input has the T-color (and the F-color when both inputs have the F-color).

Why. Say input u has the T-color. Color a with the F-color (allowed: a ≠ u), b with the B-color (allowed: b ≠ v since v is T or F, not B), and then out with the remaining T-color — a proper coloring of the triangle. (The case "both inputs F" was handled on the companion page: out is then the F-color.) So the gadget never blocks us: we can always set out to match $\mathrm{OR}(u,v)$.

One input T ⟹ we can complete the gadget with out = T.

Step 4 — Color every clause so its output is the T-color

Take a clause $(\ell_1 \lor \ell_2 \lor \ell_3)$. Because the assignment satisfies $\varphi$, the clause is true, so at least one literal is True — that literal's vertex already has the T-color from Step 2. We color the two chained gadgets so that the final output $o_2$ gets the T-color:

  • If $\ell_1$ or $\ell_2$ is True, then one input of $o_1 = \mathrm{OR}(\ell_1,\ell_2)$ is T-colored, so by the Lemma color $o_1$ with the T-color. Now an input of $o_2 = \mathrm{OR}(o_1,\ell_3)$ is T-colored, so color $o_2$ with the T-color.
  • If $\ell_1$ and $\ell_2$ are both False (so $\ell_3$ must be True), color $o_1$ with the F-color. Then $o_2 = \mathrm{OR}(o_1,\ell_3)$ has the T-colored input $\ell_3$, so by the Lemma color $o_2$ with the T-color.

Either way $o_2$ takes the T-color, which is consistent with the forcing edges $o_2\!-\!F$ and $o_2\!-\!B$ (since the T-color differs from both F and B). The clause gadget is now fully and properly colored — here is the case $\ell_1=$ True, $\ell_2=\ell_3=$ False:

A satisfied clause, fully colored: the true literal lets us drive o₂ to the T-color (every edge is proper).

Every vertex is colored and every edge joins two different colors, so this is a proper 3-coloring of $G_\varphi$. Therefore: if $\varphi$ is satisfiable, then $G_\varphi$ is 3-colorable. $\blacksquare$

A concrete example

Take $\varphi = (x \lor y \lor z)$ with the satisfying assignment $x = y = z = $ True. Step 2 colors x, y, z with the T-color (green) and ~x, ~y, ~z with the F-color (red); Step 4 completes the gadgets so o₂ is green. The result is a genuine proper 3-coloring:

The 3-coloring built from $x=y=z=$ True — the same picture the other page read the assignment from.

Both halves together

With the companion page (3-colorable ⟹ satisfiable) this completes the equivalence $$G_\varphi \text{ is 3-colorable} \iff \varphi \text{ is satisfiable}.$$ A satisfying assignment becomes a coloring (this page) and a coloring becomes a satisfying assignment (the other page) — the two operations are inverses. That two-way correspondence is exactly what makes graph 3-coloring at least as hard as 3-SAT.
