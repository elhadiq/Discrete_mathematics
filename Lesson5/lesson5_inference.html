  • If you have cherries, you can eat.   $\mathit{have} \Rightarrow \mathit{eat}$
  • You have cherries.   $\mathit{have}$

Intuitively, by inference, this implies you can eat. But how do you get there?

Limits of Truth Tables

Simplification through equivalences is often insufficient to obtain conclusive results:

Python — imports (run once) from sympy import symbols, Or, And, simplify_logic from sympy.logic.boolalg import truth_table from itertools import combinations
Python a, b, c, d, e = symbols('a b c d e') # BooleanCountingFunction[2, 5]: at least 2 of 5 are True expr = Or(*[And(x, y) for x, y in combinations([a,b,c,d,e], 2)]) simplified = simplify_logic(expr) print(simplified) # still complex # Truth table: 2^5 = 32 rows — too large to inspect by hand for vals, result in truth_table(simplified, [a, b, c, d, e]): print(list(vals), '->', result)

With 5 variables a truth table has $2^5 = 32$ rows. Rules of inference provide a structured shortcut.

Rules of Inference

The most common rules are as follows. Unlike equivalence, the right-hand side is weaker.

RulePremisesConclusion
Modus Ponens $p \;\wedge\; (p\to q)$$\to$$q$
Modus Tollens $\neg q \;\wedge\; (p\to q)$$\to$$\neg p$
Hypothetical Syllogism $(p\to q) \;\wedge\; (q\to r)$$\to$$p\to r$
Disjunctive Syllogism $(p\vee q) \;\wedge\; \neg p$$\to$$q$
Addition $p$$\to$$p\vee q$
Simplification $p\wedge q$$\to$$p$
Conjunction $p \;\wedge\; q$$\to$$p\wedge q$
Resolution $(p\vee q) \;\wedge\; (\neg p\vee r)$$\to$$q\vee r$
Python — verify all rules from sympy import symbols, And, Or, Not, Implies from sympy.logic.inference import satisfiable p, q, r = symbols('p q r') # A rule is valid iff premises & ~conclusion is UNSAT checks = { 'Modus Ponens': And(p, Implies(p,q), Not(q)), 'Modus Tollens': And(Not(q), Implies(p,q), p), 'Hyp. Syllogism': And(Implies(p,q), Implies(q,r), Not(Implies(p,r))), 'Disj. Syllogism': And(Or(p,q), Not(p), Not(q)), 'Resolution': And(Or(p,q), Or(Not(p),r), Not(Or(q,r))), } for name, f in checks.items(): print(name, ':', not satisfiable(f)) # all True

Example 1

Assume the following statements as true:

  • You will go swim or go to the gym.   $\mathrm{Swim(you)} \vee \mathrm{Gym(you)}$
  • If you go swimming, you will need a swimsuit.   $\mathrm{Swim(you)} \to \mathrm{Swimsuit(you)}$

Is it true that you will need a swimsuit or go to the gym?   $\mathrm{Swimsuit(you)} \vee \mathrm{Gym(you)}$

  • Using a conditional equivalence: $\neg\,\mathrm{Swim(you)} \vee \mathrm{Swimsuit(you)}$
  • Using resolution:   $\mathrm{Swimsuit(you)} \vee \mathrm{Gym(you)}$
Python from sympy import symbols, And, Or, Not, Implies from sympy.logic.inference import satisfiable Swim, Gym, Swimsuit = symbols('Swim Gym Swimsuit') premises = And(Or(Swim, Gym), Implies(Swim, Swimsuit)) conclusion = Or(Swimsuit, Gym) # Valid if premises & ~conclusion is unsatisfiable print(not satisfiable(And(premises, Not(conclusion)))) # True

If you sell your Invisible Rock ($\mathrm{Sell(Rock)}$), can you buy yourself a car?

Example 2 (continued)

  1. Hypothetical syllogism:   $\mathrm{Sell(Rock)} \to \mathrm{Get(\$7000)}$
  2. Modus ponens:   $\mathrm{Get(\$7000)}$
  3. Conjunction:   $\mathrm{Get(\$7000)} \wedge \mathrm{Savings(\$3000)}$
  4. Addition + Modus ponens:   $\mathrm{Have(\$10\,000)}$
  5. Modus ponens:   $\mathrm{Buy(Car)}$
Python from sympy import symbols, And, Implies, Not from sympy.logic.inference import satisfiable SellRock, Get7000, Have10000, BuyCar, Savings = symbols( 'SellRock Get7000 Have10000 BuyCar Savings') premises = And( SellRock, Implies(SellRock, Get7000), # hyp. syllogism (steps 1&2) Savings, Implies(And(Get7000, Savings), Have10000), # addition principle Implies(Have10000, BuyCar), ) print(not satisfiable(And(premises, Not(BuyCar)))) # True

Rules for Quantified Statements

Inference is also used for quantifiers:

RulePremiseConclusion
Universal Instantiation $\forall x\,P(x)$$\to$$P(c)$
Universal Generalization $P(c)$ for arbitrary $c$$\to$$\forall x\,P(x)$
Existential Instantiation $\exists x\,P(x)$$\to$$P(c)$ for some $c$
Existential Generalization $P(c)$ for some $c$$\to$$\exists x\,P(x)$

All humans live on Earth: $\forall x\,(H(x)\to L(x))$.   You are human: $H(\text{you})$.   Therefore: $L(\text{you})$

Python — Z3 from z3 import DeclareSort, Function, BoolSort, Const, ForAll, Implies, Solver, Not Person = DeclareSort('Person') you = Const('you', Person) x = Const('x', Person) H = Function('H', Person, BoolSort()) L = Function('L', Person, BoolSort()) s = Solver() s.add(ForAll([x], Implies(H(x), L(x)))) # ∀x: H(x) → L(x) s.add(H(you)) # H(you) s.add(Not(L(you))) # assume ¬L(you) — contradiction? print(s.check()) # unsat => L(you) is derived

Example: Exam & Director

Assume the following statements as true:

  • If no one cheated last exam, no one would meet the director.   $\neg\exists x\,\mathrm{Cheat}(x) \to \neg\exists x\,\mathrm{Director}(x)$
  • Octave, the class president, met the director.   $\mathrm{Director(Octave)}$
  • No one cheated or someone will get a detention.   $\neg\exists x\,\mathrm{Cheat}(x) \vee \exists x\,\mathrm{Detention}(x)$

Will someone get a detention? Using existential generalization → modus tollens → disjunctive syllogism:

$\exists x\,\mathrm{Director}(x)$  ⟹  $\exists x\,\mathrm{Cheat}(x)$  ⟹  $\exists x\,\mathrm{Detention}(x)$

Python from sympy import symbols, And, Or, Not, Implies from sympy.logic.inference import satisfiable ExCheat, ExDirector, ExDetention = symbols('ExCheat ExDirector ExDetention') premises = And( Implies(Not(ExCheat), Not(ExDirector)), # ¬ExCheat → ¬ExDirector ExDirector, # Director(Octave) ⟹ ExDirector Or(Not(ExCheat), ExDetention), # ¬ExCheat ∨ ExDetention ) # Modus tollens: ExDirector ⟹ ExCheat; disj. syllogism ⟹ ExDetention print(not satisfiable(And(premises, Not(ExDetention)))) # True

Summary

  • The main rules of inference are modus ponens, modus tollens, hypothetical syllogism, disjunctive syllogism, addition, simplification, conjunction and resolution.
  • Quantified rules of inference are universal instantiation, universal generalization, existential instantiation and existential generalization.
  • These rules make it easy to extract useful conclusions out of compound propositions.
  • You should now have a good understanding of logic.
