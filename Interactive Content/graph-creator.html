Mini créateur de graphe

(optionnel)  |  Couleur :

Sommet : cliquez sur une zone vide (la couleur choisie est appliquée). Arête / Arc : cliquez sur un premier sommet puis sur un second ; remplissez le champ Poids avant pour une pondération (affichée sur le trait), sinon laissez-le vide. Déplacer : dans ce mode, faites glisser les sommets. Sélection : cliquez sur des sommets ou tracez un rectangle pour les sélectionner, puis faites glisser un sommet sélectionné pour déplacer tout le groupe (☑ Tout sélectionne tout le graphe). Couleur : choisissez une pastille puis cliquez sur des sommets. Renommer : cliquez sur un sommet ou sur une arête/arc pour changer son nom ou son poids. Supprimer : cliquez sur un sommet, une arête ou un poids. 💾 SVG : télécharge le graphe en image vectorielle.
