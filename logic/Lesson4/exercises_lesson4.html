Ex 1 Predicate over a Finite Domain lambda

Define a predicate $P(x)$: "$x$ is even" as a Python lambda over the domain $\{1, 2, \ldots, 10\}$.

  • Evaluate $P$ at every point in the domain.
  • List all witnesses — elements for which $P(x)$ is True.
  • How many witnesses are there? What fraction of the domain do they cover?
Ex 2 Universal Quantifier — Finite Domain ∀

Check whether $\forall x \in D,\; P(x)$ holds by testing every element of the domain $D = \{1, 2, 3, 4, 5\}$.

  • Test $P_1(x)$: "$x > 0$" — does it hold for all elements?
  • Test $P_2(x)$: "$x$ is even" — does it hold for all elements?
  • For $P_2$, find and print the counterexample (the first $x$ where $P_2(x)$ fails).
Hint: Use all(P(x) for x in domain) and next(x for x in domain if not P(x)).
Ex 3 Existential Quantifier — Finite Domain ∃

Check whether $\exists x \in D,\; P(x)$ holds over the domain $D = \{-5, -4, \ldots, 5\}$.

  • Test $P_1(x)$: "$x < 0$" — does at least one element satisfy it?
  • Test $P_2(x)$: "$x > 10$" — does at least one element satisfy it?
  • For $P_1$, find and print a witness (any $x$ where $P_1(x)$ is True).
Hint: Use any(P(x) for x in domain) and next(x for x in domain if P(x), None).
Ex 4 Z3: Universal Quantifier over ℝ Z3 · ForAll · prove

Use Z3 to reason about universal quantification over the real numbers.

  • Prove $\forall x \in \mathbb{R},\; x^2 \ge 0$ using z3.prove(ForAll([x], x**2 >= 0)).
  • Show that $\forall x \in \mathbb{R},\; x^2 > 0$ is not valid by finding a counterexample with a Solver.
  • Print the counterexample value of $x$.
Hint: To find a counterexample to $\forall x\; P(x)$, add $\neg(\forall x\; P(x))$ to the solver and check for sat.
Ex 5 Z3: Existential Quantifier — Real vs Integer Z3 · Solver

Use Z3 to determine the satisfiability of $\exists x,\; x^2 = 2$ in two different domains:

  • Over $\mathbb{R}$ using z3.Real('x') — expected result: sat (since $x = \sqrt{2}$).
  • Over $\mathbb{Z}$ using z3.Int('x') — expected result: unsat (no integer solution).

What does this demonstrate about the importance of the domain in quantified statements?

Ex 6 Negation of Quantifiers Z3 · Solver

Demonstrate the duality laws using Z3:

  • $\neg(\forall x,\; x > 0) \;\equiv\; \exists x,\; x \le 0$: find a witness for $x \le 0$ over $\mathbb{R}$.
  • $\neg(\exists x,\; x^2 < 0) \;\equiv\; \forall x,\; x^2 \ge 0$: show no witness for $x^2 < 0$ exists (result: unsat).
Reminder: $\neg\forall x\; P(x) \equiv \exists x\; \neg P(x)$ and $\neg\exists x\; P(x) \equiv \forall x\; \neg P(x)$.
Ex 7 Quantifier Elimination Z3 · Tactic('qe')

Use Z3's quantifier elimination tactic to simplify the statement:

$$\exists (x, y) \in \mathbb{R}^2,\quad x^2 + a \cdot y^2 \le 1 \;\land\; x - y \ge 2$$

This eliminates $x$ and $y$ and produces a constraint on the parameter $a$ alone.

  • Declare x, y, a = Reals('x y a').
  • Create a Goal, add the Exists formula, apply Tactic('qe').
  • Print the resulting constraint on $a$.
Ex 8 Nested Quantifiers — Order Matters Z3 · ForAll · Exists

Quantifier order changes the meaning. Compare the two statements over $\mathbb{R}$:

  • $\forall x \;\exists y,\; x + y = 0$ — for every $x$ there is a $y$ (namely $y = -x$). Use z3.prove.
  • $\exists x \;\forall y,\; x + y = 0$ — one fixed $x$ works for every $y$. Check validity with a Solver.

Which statement is valid? Which is not? Explain the difference.

Ex 9 Binary Predicate — Divisibility Relation lambda

Define the binary predicate $R(x, y)$: "$x$ divides $y$" (i.e., $y \bmod x = 0$) over the domain $\{1, 2, 3, 4, 5, 6\} \times \{1, 2, 3, 4, 5, 6\}$.

  • List all pairs $(x, y)$ for which $R(x, y)$ is True.
  • How many such pairs are there?
  • Is the relation reflexive? (Does $x \mid x$ for every $x$?)
Ex 10 Z3: Predicate over a Declared Sort Z3 · DeclareSort · Function

Encode the classic syllogism in Z3 using an uninterpreted sort Person:

  • Declare uninterpreted functions $H(\cdot)$ ("is human") and $M(\cdot)$ ("is mortal") mapping Person → Bool.
  • Add the universal axiom: $\forall x,\; H(x) \to M(x)$.
  • Add the fact: $H(\text{socrates})$.
  • Assume $\neg M(\text{socrates})$ and check for unsat — this proves $M(\text{socrates})$ follows.
Hint: Use DeclareSort, Const, Function, BoolSort from Z3.
Ex 11 Region Inclusion — R2 ⊆ R1 Z3 · Solver

Define two regions in $\mathbb{R}^2$:

  • $R_1$: the disk of radius 2 — $x^2 + y^2 \le 4$
  • $R_2$: the disk of radius 1 — $x^2 + y^2 \le 1$

Use Z3 to:

  • Prove $R_2 \subseteq R_1$ by showing no point can be in $R_2$ but outside $R_1$ (expected: unsat).
  • Find a point that is in $R_1$ but not in $R_2$ (expected: sat; print the witness).
